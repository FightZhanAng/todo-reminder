# 手动验收清单（第一期）

跑之前把数据文件删掉，从干净状态开始：
`%APPDATA%/todo-reminder/todo-reminder.json`

造测试数据的方法：直接编辑该 JSON，往 `tasks` 数组里塞一条，然后重启应用。
一条截止型任务的最小结构：

```json
{
  "kind": "deadline",
  "id": "manual-1",
  "title": "验收测试",
  "important": false,
  "createdAt": <今天早上 8 点的时间戳>,
  "updatedAt": <同左>,
  "deletedAt": null,
  "firedFor": null,
  "pushedFor": null,
  "dueAt": <距今 1 分钟后的时间戳>,
  "allDay": false,
  "leadMin": 15,
  "snoozeUntil": null,
  "completedAt": null
}
```

注意 `leadMin: 15` 意味着提醒点比 `dueAt` 早 15 分钟 —— 想让提醒在 1 分钟后
触发，`dueAt` 要设成 16 分钟后。
